The artifact

It leaves something behind.

Every other tool closes a tab. This one writes a folder that outlives the session.

my-new-project/
├── .devcontext/            the project brain
│   ├── context.json         what was chosen, and why
│   ├── semantic_cache.db    portable vector store
│   ├── open_source_maps/    vetted tooling per node
│   └── trends_report.md     community risk log
└── init.sh                  one command bootstrap

$ bash init.sh
[clone] rxdb          → reference/
[clone] fastify       → reference/
[deps]  Node detected → npm install

context.json is the point

A structural ledger recording not just the stack but the reasoning. It stays in the repo as a permanent brief for the next teammate — or the next AI coding agent.

Rationale is composed from evidence

Never generated by the model. A hallucinated justification in a file that outlives the project is worse than none at all.

Search results are untrusted input

init.sh shallow-clones vetted repos read-only into reference/ and resolves dependencies only from your own manifests. No blind installs.

Cross-device bridge

Office Kit is the product, not a checkbox.

The handoff generates bridge activity because it is the core loop — nothing was bolted on for telemetry.

Shared clipboard

The compiled node-graph payload crosses as structured JSON, phone to laptop.

File transfer

Larger payloads and build bundles move by drag-and-drop across the bridge.

Remote control

Laptop keyboard drives phone fields through screen mirroring during Red Light.

PHONE compiles payload OFFICE KIT clipboard + file CLI LISTENER writes .devcontext/
Precise about the mechanism: the bridge transports the payload; the CLI listener performs the filesystem write. A clipboard cannot create a directory, and we do not claim it does.
