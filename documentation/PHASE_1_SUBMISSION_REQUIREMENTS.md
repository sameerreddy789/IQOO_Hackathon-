## 📋 Required Submission Fields & Guidelines

Below is the complete checklist of fields required for the Phase 1 idea submission form:

| Field Name | Type | Requirement / Limit | Guidance & Shortlisting Strategy |
| :--- | :--- | :--- | :--- |
| **Idea Title** | Text | **Required** (Min 5 chars) | A short, punchy, memorable project name. Should reflect the product's core value proposition. |
| **Description** | Long Text | **Required** (Min 50 chars) | Must answer **What are you building, for whom, and how?** Explicitly highlight local model execution on Snapdragon NPU, Office Kit integration, and creative sensor usage. |
| **Video Walkthrough URL** | URL | *Optional* | YouTube link showcasing concept video, wireframe, or voiceover pitch. |
| **Prototype URL** | URL | *Optional* | Link to live demo web app, staging link, or GitHub repo ([sameerreddy789/IQOO_Hackathon](https://github.com/sameerreddy789/IQOO_Hackathon)). |
| **Deck / Document** | File / Link | **Required** | PDF or PPT upload (Max 25 MB) OR external link (Google Slides / Google Drive / Figma). |
| **Android Proficiency** | Dropdown / Selection | **Required** | Self-assessed proficiency level (No experience / Beginner / Intermediate / Advanced). |
| **LLM Proficiency** | Dropdown / Selection | **Required** | Self-assessed proficiency level (No experience / Beginner / Intermediate / Advanced). |
| **Prior Builds & Hackathons** | Long Text | **Recommended** | Past hackathon wins, shipped products, OSS repos, or work experience. Crucial for shortlisting evaluation. |
| **What Makes Team Stand Out** | Long Text | **Recommended** | Team skills, domain edge, prior collaboration experience, and personal motivation for solving this problem. |
| **Originality Confirmation** | Checkbox | **Required** | Confirmation that the idea is original work and any pre-existing code/libraries are disclosed. |

## 🎯 Scoring Criteria Alignment Checklist

To ensure your Phase 1 pitch deck and description achieve maximum shortlisting points, align your pitch with these core hackathon parameters:

> [!TIP]
> **Shortlisting Maximizer**:
>
> 1. 📱 **On-Device Local AI**: Emphasize running quantized open-source models (e.g. ExecuTorch / ONNX / Llama 3 / Phi-3) locally on the Snapdragon NPU.
> 2. 🔄 **Office Kit Integration**: Explain how your phone app interacts seamlessly with the developer laptop using Office Kit (shared clipboard, remote control, file transfer).
> 3. 🎥 **Sensors & Hardware**: Detail how the app leverages the camera, microphone, BLE, or accelerometers.
> 4. 🛠️ **Real-World Impact**: Target a clear Indian user persona or workflow problem.
